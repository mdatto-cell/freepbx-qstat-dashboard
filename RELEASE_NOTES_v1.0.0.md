# DashBoard for FreePBX — v1.0.0

Первый публичный релиз исходников DashBoard — мобильного дашборда статистики звонков очередей FreePBX / Asterisk.

## Состав релиза

- **Android v2.4**: Java-приложение, темы, отображение статусов, прослушивание записей (при наличии), вызов клиента через выбранного агента, автоматическая регистрация FCM-токена и переход в пропущенные из push.
- **iOS v1.6**: SwiftUI, настройки подключения, загрузка имени из API, вызов клиента, Firebase Cloud Messaging с APNs, автоматическая регистрация push-токена и навигация в пропущенные.
- **FreePBX QStat**: PHP API, скрипты синхронизации входящих, исходящих и callback-звонков, интеграция с Asterisk AMI, push worker FCM HTTP v1.
- **База данных**: установочные SQL-схемы `cc_calls_report`, `cc_etl_state`, `cc_push_devices`, `cc_push_events`, `cc_push_deliveries` и другие таблицы проекта.
- **Документация**: README, настройка сервера, cron, Firebase Android, Firebase iOS, APNs в Apple Developer и диагностика.

## Что умеет система

- Показывать входящие, исходящие и пропущенные звонки в очередях.
- Показывать сведения о клиентах, агентах и статусах обратного звонка.
- Воспроизводить доступные записи разговоров; для разговоров длительностью 00:00 кнопка прослушивания не отображается.
- Инициировать звонок клиенту через разрешённый внутренний номер агента.
- Отправлять push по пропущенным звонкам на Android и iPhone с открытием раздела «Входящие → Пропущенные».

## Подготовка к установке

1. Используйте примеры конфигураций вместо публикации рабочих секретов.
2. Импортируйте SQL-схемы только при первоначальной установке; сохраняйте резервные копии работающих баз данных.
3. Настройте PHP 5.6, MariaDB, Asterisk AMI и рабочий cron.
4. Создайте собственный Firebase-проект и файлы `google-services.json` и `GoogleService-Info.plist` для соответствующих приложений.
5. Для iOS настройте APNs Authentication Key в Apple Developer и Firebase Cloud Messaging. Для TestFlight требуется Production APNs.
6. Проверьте `cc_push_devices`, `cc_push_events`, `cc_push_deliveries` и тестовую отправку через `push_test.php`.

Подробности см. в [README](README.md) и [инструкции по развёртыванию](docs/DEPLOYMENT.md).

## Совместимость и версии

- Android: **2.4**, package `com.freepbx.qstat`
- iOS: **1.6**, Bundle ID `ru.freepbx.qstat.ios`
- Сервер: FreePBX QStat, PHP 5.6, MariaDB 5.5 (по исходной установке)

**v1.0.0** — общая версия первого публичного набора исходников, а не изменение номеров версий Android и iOS.

## Ограничения

- Подписанные APK/IPA в релиз не входят: мобильные приложения собираются локально в Android Studio и Xcode.
- `call.php` и `recordings.php` пока остаются отдельными endpoint-файлами; перенос в авторизованный API запланирован.
- Не публикуйте рабочие пароли и закрытые ключи. После предыдущей публикации примера пароля БД значение необходимо сменить, поскольку старые коммиты Git могут сохранять историю.
- Это публикация исходников; проверка сборки и работоспособности в собственном окружении обязательна.
