# Текущее решение по объёму изменений

- Текущий deployment: малая внутренняя группа ресторана (порядка пяти пользователей); API доступен через настроенный Nginx reverse proxy.
- **Не менять** логику `call.php`, `recordings.php`, мобильных приложений, FCM/APNs и действующего cron.
- В следующей версии: перенести обращения к звонкам и записям в авторизованный `api.php`.
- **Удалены только `DROP TABLE IF EXISTS` в экспортированных копиях шести SQL-схем.** Исходный архив `qstat.zip` и действующая база не изменены.
- `examples/qstat.cron.example` — самостоятельный пример с `flock` каждые 15 секунд; не заменяет текущую настройку.
- Исходный `INSTALL.txt` содержит обрезанные строки cron; точные действующие строки можно получить только из crontab сервера.
