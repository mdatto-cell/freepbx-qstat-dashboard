# FreePBX QStat — Android (native Java)

Порт интерфейса и API-контракта из предоставленного FreePBXQStat-iOS-v1.4.

## Сборка APK

Требуется JDK 17 и Android SDK Platform 35, Android Build Tools 35, Gradle 8.9+ (либо установленный Android Studio). В каталоге проекта выполните `gradle assembleDebug`. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Проект без сторонних библиотек. `gradlew` не включён, поскольку бинарный Gradle Wrapper недоступен в текущей среде.

## Возможности

Подключение к api.php с Bearer-токеном, зашифрованным Android Keystore (AES-GCM); входящие/исходящие; календарь одного дня; все статусы v1.4; KPI; карточки; пагинация по 100; ручное обновление; записи через recordings.php по uniqueid / outgoing_id; локальный MediaPlayer с перемоткой; отключение и очистка токена.

## Замечания

Для разделения NO ANSWER и BUSY нужен серверный api.php из архива iOS v1.4. Скрипт recordings.php должен существовать на сервере рядом с api.php и сам обеспечивать защиту записей. HTTP разрешён для совместимости, но в рабочей сети рекомендуется HTTPS. Проект не был собран и не проверялся на устройстве из-за отсутствия Android SDK и доступа к загрузке инструментов в текущей среде. Для точного соответствия внешнего вида SwiftUI требуется дополнительная визуальная проверка на устройстве.
