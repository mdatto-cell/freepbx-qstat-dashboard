# FreePBX QStat Android 1.9 — ручной тест Firebase Push

## Что добавлено
- Firebase Messaging SDK и конфигурация google-services.json из вашего Firebase-проекта.
- Запрос разрешения на уведомления (Android 13+).
- Канал уведомлений «Пропущенные звонки».
- В настройках приложения (шестерёнка) пункт «FCM-токен» с кнопкой «Копировать».
- Обработка push в активном приложении. Когда приложение в фоне, notification-сообщения обычно показывает сама система Android.

## Проверка
1. Откройте проект в Android Studio и дождитесь Gradle Sync (потребуется интернет для Firebase SDK).
2. Соберите Build → Build APK(s), установите APK на Android с Google Play services.
3. Разрешите уведомления при первом запуске. Подключитесь к Dashboard как обычно.
4. Нажмите шестерёнку → FCM-токен → Копировать. Передайте токен себе на ПК безопасным способом. Не публикуйте токен.
5. В Firebase Console откройте Messaging / Cloud Messaging → создание кампании Notifications (названия меню могут меняться). Введите заголовок «Пропущенный звонок» и текст «Тест FreePBX QStat».
6. Используйте «Send test message» / «Отправить тестовое сообщение», вставьте FCM-токен устройства и отправьте.
7. Сверните приложение перед тестом; уведомление должно появиться в шторке Android. Затем повторите с открытым приложением.

## Важно
- На данном этапе PHP API и cron не изменены. Токен не отправляется на ваш сервер.
- Для теста из Firebase Console серверный JSON-ключ не нужен.
- Не путайте google-services.json (конфигурация клиента) и JSON service account (секретный ключ сервера).
- Успешная отправка не гарантирует доставку: влияют настройки уведомлений, Google Play services, сеть и ограничения устройства.
- Проект не был скомпилирован в этой среде. Проверьте Gradle Sync и сборку на Windows.
