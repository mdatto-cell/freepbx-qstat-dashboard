# Первичный аудит приложенных архивов

Статус: **BLOCKED FOR PUBLIC GITHUB** до ручной очистки и ротации секретов. Это анализ исходного состава, **не** пентест и **не** доказательство отсутствия других секретов.

## Подтверждено

- `qstat/qstat.inc.php` содержит реальные значения параметров БД/AMI/API и конфигурации внешнего сервиса; его нельзя добавлять в GitHub. Содержимое намеренно не перепечатано здесь. Требуется заменить секреты безопасными переменными, отозвать опубликованные/скомпрометированные значения и пересоздать образец конфигурации.
- Оригинальный `qstat.zip` содержит SQL-дампы с `DROP TABLE IF EXISTS`. В приложенных документационных копиях из `database/schema/` эти команды удалены; оригинальные дампы не исправлялись.
- `qstat/INSTALL.txt` содержит опечатку в имени push-таблицы и обрезанные cron-команды.
- `qstat/recordings.php` принимает `uniqueid`/`outgoing_id`; в видимой части файла нет полноценной проверки Bearer-токена — необходимо проверить возможность неавторизованной загрузки аудио. Владелец отложил перенос функции на следующий релиз; текущее поведение оставлено без изменений.
- `qstat/api.php` при включённой авторизации проверяет Bearer, но для GET допускает fallback `?token=`; URL-токены могут попадать в логи.
- `qstat/call.php` имеет мобильный POST Bearer и веб-GET с CSRF, ограничение 2 с на агента/токен. Проверить разграничение прав на доступ к данным и исходящим звонкам.
- `AndroidManifest.xml` включает `android:usesCleartextTraffic="true"`, что позволяет нешифрованные обращения при определённых условиях.
- `push_worker.php` создаёт доставки ко всем активным устройствам для событий последней недели; нет пользовательской сегментации по правам/очередям. Учтите при подключении руководителей.
- Android `google-services.json` и iOS `GoogleService-Info.plist` включены в проекты: это клиентские конфиги Firebase, а не серверный приватный service-account key. Для независимого развёртывания необходимы **свои** файлы.
- Приложенные архива **не содержат** отдельных файлов Asterisk `extconfig_custom.conf` / `logger_general_custom.conf` или AMI-конфигурации; в `INSTALL.txt` есть только фрагменты. Полноту настройки Asterisk по архивам подтвердить нельзя.

## Рекомендации до публикации

По решению владельца проекта, используемого малой группой внутри организации, архитектурные изменения авторизации `call.php` и `recordings.php` переносятся на следующий релиз. Это не отменяет необходимости убрать реальные ключи и пароли из публичного GitHub. Оригинальные рабочие файлы и расписание cron не изменялись.
